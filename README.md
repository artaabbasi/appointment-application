# Appointment application
A monolithic modular backend.

### Run locally
- Fill out `.env.example` and rename it to `.env`. 
- Setup dependencies
  - Install `poetry` with `curl -sSL https://install.python-poetry.org | python3 -`.
  - Install the dependencies with `poetry install`.
  - Activate poetry env with `poetry shell`.
  - install pyenv using [this link](https://github.com/pyenv/pyenv)
  - install python version 12 using `pyenv install 3.12`
  - use python version 12 using pyenv command `poetry env use {path to python 12}`
    -  further information on this [link](https://python-poetry.org/docs/managing-environments/) is available 
- Run with uvicorn
  - Navigate into `src` directory.
  - Run `uvicorn main:app --reload --port 8000`.

Now swagger documentation should be available at [http://localhost:8000/docs](http://localhost:8000/docs).

#### Migration Commands
- first move to src/database directory with `cd src/database`
- to run revision migrations use `alembic upgrade head`
- to add new revision use `alembic revision -m “baseline_revision”` which will generate an empty script with upgrade() and downgrade() functions.
- to downgrade last revision use `alembic downgrade -1` 
- to run migration for already created entity use `alembic revision --autogenerate -m "Added account table"`
  - to complete process, created entity should be imported in follwing files too.
    - `database/run_migrations.py`
    - `database/migrations/env.py`
  - which in this condition, the table migration will be **autogenerated**

#### Test Commands
- to run tests simply type `pytest`
- to run certain file simple add filepath after `pytest` comment 
  - for example `pytest src/service/user/service/auth_service_test.py`

### API Documentation
- Swagger documentation is available at http://localhost:8000/docs

### Generating RSA key pairs for JWT generation.
In the `.env` file you should provide a pair of public & private keys.
Use commands in this [gist](https://gist.github.com/jpf/1e860e5ea70c0a70fd5e).

**Note** that we have used `openssl` tool with specified options at [the gist](https://gist.github.com/jpf/1e860e5ea70c0a70fd5e)
for key generation. So stick to it.
